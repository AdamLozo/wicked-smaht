## Recording Notes

1. **Audio format:** MP3, 44.1kHz, mono or stereo
2. **Delivery:** Natural, conversational pace - these are spoken reactions during gameplay
3. **Length:** Most lines are 5-15 seconds when spoken naturally
4. **Emotion:** "Correct" reactions should have a hint of approval/respect; "Wrong" reactions should have mild disappointment but still be educational

## Placeholder Behavior

The game code will gracefully handle missing voice files - if a file doesn't exist, the reaction will display as text-only with a 1-second delay before advancing. Once voice files are added, the reaction will wait for the audio to complete before advancing.
